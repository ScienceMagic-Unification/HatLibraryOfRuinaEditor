# 更新日志

## V0.2.0
- 新增「奇点」大工作区：内置图片（射程/骰子/章节/奇点/原版/其他，只读）、原版正则、奇点正则、模组正则
- 新增「被动」大工作区：被动能力数据 + 名称与描述本地化，含属性、稀有度、互斥类型（自定义互斥类型 / 与指定被动互斥）
- 新增「效果文本」工作区（BattleEffectText / BattleEffectTextExtra）
- 新增「图片」大工作区：书页图片、Buff图标、其他图片，支持导入/删除/重命名/手动重定向/路径记忆/平铺与文件夹视图
- 新增正则预览引擎：`[X]` 黄字+小空格、`(~`/ `~)` 转 `<`/`>`、`<u>` 等 HTML 格式；开启帽子奇点后渲染 HatKeyword / HatKeywordLink / HatKeywordIcon 内联引用
- 模组正则读取当前 Mod 的 EffectText 中 BattleEffectTextExtra，并参与正则替换
- 战斗书页：简略/详细/源码三模式；预览显示卡图、费用、射程、能力、骰子；稀有度/章节/射程/目标/特性单选框；骰子列表动作与骰子图标；书页图片/能力/骰子能力自动补全
- 书页名称/书页能力：本地化文档选择（含「无」）、一键同步名称、删除孤儿、校对模式与校对预览
- 本地化扫描增强：扫描整个 Mod 并自适应分配工作区，支持复数本地化文档切换与语言检测
- 界面：编辑器语言切换（中/英/日）、未保存关闭二次确认、记住上次 Mod 与文件、区域独立滚动与表头冻结
- 内置资源整理为 图片/正则 子文件夹并同步打包
- 修复：本地化文档按钮、模组正则空列表、首次打开名称与描述本地化不跟随、图片递归读取、滚动逻辑等

## V0.1.2
- 书页能力校对模式新增“校对预览”开关，开启后能力描述中的 [X] 正确显示为黄色文本 + 小空格
- 修复：书页能力校对模式在其他语言下只显示 1 行 Desc，现已完整显示多条
- 修复：其他语言模式下，关键词输入框的占位提示、“添加”按钮、皮肤切换/地图切换等标签未翻译
- 适配 Linux：Steam 目录发现、跨平台路径拼接、AppImage / deb 打包与 CI 自动构建
- 战斗书页列表支持切换显示本地化名称
- 新增 `joinPath` 统一路径处理，修复含盘符/绝对路径的加载

## V0.1.1
- 改进本地化文件扫描：扩大扫描范围，兼容更多 `Localize` / 语言目录命名方式
- 新增按 XML 根节点兜底识别，减少漏扫与误扫
- 跳过无法解析的本地化文件，避免单个坏文件阻塞整体扫描

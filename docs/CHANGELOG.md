# 更新日志

## V0.2.5
- 新增 Windows x64 完整解压便携包（win-x64.zip），解压后直接运行应用，绕过 NSIS 临时文件初始化与自解压步骤，供单文件版出现 NSIS 临时目录错误的用户使用。
- 保留单文件便携版，明确使用 Unicode 和普通用户权限；兼容 ZIP 与单文件版使用不同附件名，避免将单文件 EXE 再压缩误当作兼容修复。
- 修正内置插件的 6 处中文列表空格及书页选项刷新说明。

## V0.2.4
- 初步新增 14 个工作区：接待、卡组、掉落书籍、书页掉落表、阵型、饰品、饰品文本、异想体书页、异想体书页文本、异想体能力文本、楼层 E.G.O、角色与接待名称、战斗对白及核心书页对白关联。
- 复用现有列表、表单、源码与预览模板，支持嵌套列表、文档级字段和节点自身文本编辑。
- 补齐敌人的核心书页、卡组、AI 脚本、情感和掉落编辑，保留重复条目、扩展节点、属性及小数值。
- ID 输入改为回车或失焦后提交，支持重复 ID 拒绝和 Esc 取消，修复输入中途误识别与撤销后的错误跳转。
- 核对 BaseMod XML 与原版程序集字段，补齐多项异想体脚本、饰品被动与接待楼层限制，完善中英日界面标签。

- 完善关键词迁移搜索、重复词条汇总及附魔骰子适用条件，保留用户文档原文。

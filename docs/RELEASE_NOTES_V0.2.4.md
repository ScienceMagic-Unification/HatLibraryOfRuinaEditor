# 帽子的废墟图书馆编辑器 V0.2.4

发布日期：2026-10-31

## 下载

- Windows x64 单文件便携版：`HatLibraryOfRuinaEditor-0.2.4-portable.exe`，下载后直接运行。
- Windows ZIP：`HatLibraryOfRuinaEditor-0.2.4-portable.zip`，包含中文命名的 EXE 和本次更新说明。
- 文件校验：`SHA256SUMS.txt`。

## 本次更新

- 初步新增 14 个工作区，覆盖接待、卡组、掉落书籍、书页掉落表、阵型、饰品及文本、异想体书页及文本、异想体能力文本、楼层 E.G.O、角色与接待名称、战斗对白及核心书页对白关联。
- 复用现有列表、表单、源码和预览样式，支持嵌套条目、文档级对白组、名称直写与 XML 保存。
- 补齐敌人的核心书页、卡组、AI 脚本、情感与掉落配置；保留有意义的重复条目、扩展节点、属性和小数值。
- 修复 ID 尚未输入完毕就被应用的问题。例如输入 `21` 时，中途的 `2` 不再触发改名或跳转；回车或失焦后提交，重复 ID 会被拒绝，Esc 可取消。
- 修复 ID 修改后的撤销、重做和跨文档选中项恢复。
- 根据 BaseMod XML 和原版程序集核对多项情感配置、异想体脚本、饰品被动及楼层限制，补齐中英日界面标签。

## 验证

- 类型检查及 89 项自动测试通过。
- 新工作区表单、预览、嵌套编辑、源码切换、增删复制与保存回读通过界面验证。
- 原核心书页的抗性、单皮肤、专属卡牌、被动预览及文档切换回归通过。
- 新工作区为初步实现，尚未进行游戏内实战验证。

## 使用

首次运行选择 Mod 根目录；可通过工作区的文档导入按钮打开匹配的 XML。便携版无需安装，未进行代码签名。

问题反馈请通过仓库 Issues 提供复现步骤和相关 XML 片段。

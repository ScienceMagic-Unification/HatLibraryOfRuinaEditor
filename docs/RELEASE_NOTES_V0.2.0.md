# 帽子的废墟图书馆编辑器 V0.2.0

## 下载
- Windows x64 单文件便携版：`HatLibraryOfRuinaEditor-0.2.0-portable.zip`（解压后运行 `帽子的废墟图书馆编辑器-0.2.0-portable.exe`）
- Linux：`HatLibraryOfRuinaEditor-0.2.0.AppImage`、`HatLibraryOfRuinaEditor-0.2.0.deb`

## 本次更新
- 新增「奇点」大工作区：内置图片、原版正则、奇点正则、模组正则
- 新增「被动」大工作区：被动能力数据与名称/描述本地化
- 新增「效果文本」工作区与「图片」大工作区（书页图片 / Buff图标 / 其他图片）
- 正则预览引擎与帽子奇点开关
- 战斗书页三模式（简略/详细/源码）与更完整的预览
- 书页名称 / 书页能力的本地化与校对工具
- 本地化扫描与多文档切换增强
- 三语界面（中/英/日）与多项体验优化

## 说明
- 首次打开会自动查找 Steam 与《废墟图书馆》游戏目录，也可手动选择 Mod 根目录；
- 保存操作自动备份，测试时建议使用 Mod 副本；
- 未签名，Windows SmartScreen 可能提示“仍要运行”；Linux 上运行 AppImage 可能需要先赋予执行权限。

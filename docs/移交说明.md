# 开发移交说明（供新对话窗口使用）

> 更新时间：2026-08-15
> 项目：废墟图书馆 XML 编辑器（LoR Mod XML Editor）
> 工作目录：D:\360data\重要数据\我的文档\ChatGPT\废墟图书馆XML编辑器

## 0. 常用命令
```powershell
cd "D:\360data\重要数据\我的文档\ChatGPT\废墟图书馆XML编辑器"
pnpm install          # 首次
pnpm dev              # 开发模式（Electron 窗口）
pnpm build            # 生产构建（apps/desktop/out）
pnpm test             # 核心引擎单测（packages/editor-core）
pnpm typecheck        # 全包类型检查
```
启动成品：`apps\desktop\node_modules\.bin\electron.CMD apps\desktop`（当前目录为 apps/desktop 时参数为 `.`）。

## 1. 目录结构
- `apps/desktop`：Electron 主进程/预加载/渲染进程
- `packages/editor-core`：XML 引擎（解析/序列化/实体读写/校验/修复/推断）
- `packages/schemas`：工作区 Schema（cardinfo/cardname/cardability/passive/enemy 等）
- `packages/ui`：设计系统组件
- `内置资源/`：射程、骰子、章节图标（复制到 `apps/desktop/src/renderer/src/assets/*` 打包）
- `docs/preview/prototype.png`：界面截图

## 2. 核心架构（重要）
- 打开 Mod 时扫描 `Data/*.xml` 与 `Assemblies/Localize/**/*.{xml,txt}`，按根节点 + 文件名兜底归类到工作区。
- 文档按“绝对路径”共享：`DocState` 含 `bindings[moduleId] = {kind:'primary'|'localize', locDef, issues}`。
- 保存：主进程原子写入 + userData/backups 备份；撤销/重做基于序列化快照。
- 字段模型在 `packages/editor-core/src/schema.ts`：text/int/enum/multiline/attrs/attr/multi/marker/list。
- 特殊规则：`locked`、`defaults`、`stripFields`、`headerFields`、`idOnlyList`、`omitWhenEmpty`、`accentFromModuleId`。
- 卡牌主题色：`lib/cardAccent.ts`；EGO 特性强制 `#C61231`。

## 3. i18n（必须遵守）
- 入口：`apps/desktop/src/renderer/src/i18n.tsx`。
- 功能/按钮文本：`const { t } = useI18n(); t('key', {var})`。
- 字段标签/枚举：`const { t, tl } = useI18n(); tl('中文原文')`。
- 新增文本必须在 `dict` 与 `labelDict` 的 zh/en/jp 三处补齐。

## 4. UI 关键文件
- `WorkspaceView.tsx`：三栏布局、模式切换、工具抽屉、文档选择器。
- `FormPanel.tsx`：详细区表单；`SummaryPanel.tsx` 通用简易区；`CardBriefPanel.tsx` 战斗书页专属简易区。
- `FieldEditor.tsx`：字段渲染（含骰子列表、图标选择、ID 切换）。
- `PreviewPanel.tsx`：战斗书页预览（本地化名称/能力/骰子）。
- `CardNameTools.tsx` / `CardAbilityTools.tsx`：右侧功能抽屉（同步、删除、校对模式）。
- `DataPanel.tsx`：列表；`ProofPanel.tsx`：校对内容。

## 5. 无界面自动验收
主进程支持环境变量：
```powershell
$env:RUINA_SCREENSHOT='out.png'      # 启动后截图并退出
$env:RUINA_SCREENSHOT_DELAY='6000'
$env:RUINA_EXEC_JS='...js...'        # 执行 JS 后截图
$env:RUINA_DUMP_TEXT='ui.txt'        # 抓取 body.innerText
$env:RUINA_ERROR_LOG='err.txt'       # 渲染错误日志
```
窗口暴露调试钩子：`window.__store`、`window.__debug.listEntities`、`window.__debug.cardAccent`。

## 6. 已知注意点
- PowerShell 写文件用 `[System.IO.File]::WriteAllText(path, content, UTF8Encoding($false))`，避免 BOM 与编码问题；替换 JSX 用 here-string。
- 本地化文件可能扩展名为 `.txt`（内容仍是 XML）。
- 列表虚拟滚动，测试远端行时用 `window.__store.getState().select('module','id')`，不要直接点未渲染行。
- 骰子合理性规则：Def+Hit/Penetrate/Slash 或 Atk+Guard/Evasion 为不合理，提示在“骰子列表”头部。
- 帽子奇点状态：`localStorage.hatSingularityEnabled`；编辑器语言：`localStorage.editorLang`；最后 Mod：`localStorage.lastModPath`。

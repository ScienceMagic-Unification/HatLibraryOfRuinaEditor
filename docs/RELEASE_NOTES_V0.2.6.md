# 帽子的废墟图书馆编辑器 V0.2.6

发布日期为 2026-11-27。

## 下载

- Windows 完整便携包为 `HatLibraryOfRuinaEditor-0.2.6-win-x64.zip`。将整个 ZIP 解压到普通文件夹，运行其中的“帽子的废墟图书馆编辑器.exe”，并保留同目录的资源和 DLL。此包适用于遇到 NSIS 临时目录错误的用户。
- Windows 单文件便携版为 `HatLibraryOfRuinaEditor-0.2.6-portable.exe`，启动时需要可写的临时目录。
- Linux 提供 `HatLibraryOfRuinaEditor-0.2.6.AppImage` 和 `HatLibraryOfRuinaEditor-0.2.6.deb`。
- 文件校验见 `SHA256SUMS.txt`。

## 更新内容

- 原版战斗书页和被动的列表名称按稀有度染色，复用 Mod 列表的配色。普通列表、本地化列表均支持，E.G.O 书页显示为红色。
- 顶部新增标注模式，可自定义标签和颜色，为卡牌、能力、被动挂载标签并快速检索。默认提供已完成、待实装、待敲定、占位符。
- 统合视图支持按 XML 分组、收起和手动排序。条目可跨 XML 拖动，联动保存、撤销及标签迁移。CardInfo 等单文件工作区支持手动分组，多选和 Shift 连选可批量移动。拖到条目时插入其下方，拖到分组标题时追加到组末尾。
- 改善长文件名和能力 ID 的展示，补全分组列表的标签显示。
- 内置指定 Combat Pages 目录的图片，并用游戏资源包补充原版卡图，支持预览、按资源名搜索和回填。模组同名图片优先显示。
- 补全原版能力文本，读取书页本地化中的能力及逐骰描述，支持简中、繁中、英文、日文和韩文。预览可跳转原版能力。
- 修正佚亡和群体攻击等标签的语言显示，并区分 Exhaust 与 Single-use。

## 资源范围

原版 XML 引用的 795 个不同卡图名中，790 个已匹配。其余 5 个在本次核对的资源中缺图。使用者无需安装开发机上的图片目录或游戏来访问已内置资源。

软件未进行代码签名。Linux 产物通过 GitHub Actions 构建，桌面交互验证在 Windows 上执行。

## 验证

- 类型检查和 98 项自动测试通过。
- 已打包 Windows 应用通过原版战斗书页与被动的四档稀有度、E.G.O 红色及普通与本地化列表验收。

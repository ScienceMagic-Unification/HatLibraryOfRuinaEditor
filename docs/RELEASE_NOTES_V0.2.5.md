# 帽子的废墟图书馆编辑器 V0.2.5

发布日期：2026-11-01

## 下载与启动

- **遇到 NSIS Error 的用户，请下载 `HatLibraryOfRuinaEditor-0.2.5-win-x64.zip`。** 将整个 ZIP 解压到普通文件夹，再双击里面的“帽子的废墟图书馆编辑器.exe”。请保留旁边的 resources、locales 和 DLL 等全部文件，不要在压缩包预览里直接运行。
- 单文件便携版：`HatLibraryOfRuinaEditor-0.2.5-portable.exe`，仍需要可写的 Windows 临时目录。
- 文件校验：`SHA256SUMS.txt`。

## 本次更新

- 新增包含完整应用的 Windows x64 兼容便携包，绕过 NSIS 初始化临时文件及自解压应用步骤。旧版 `portable.zip` 只是把 NSIS 单文件放进 ZIP，不能解决此类错误；本次新增的 `win-x64.zip` 可直接从解压目录运行。
- 保留单文件版本，明确 Unicode 与普通用户执行级别，无需管理员权限。兼容修复在 `win-x64.zip` 中，单文件启动器仍依赖临时目录。
- 修正内置插件 6 处中文列表空格，以及“书页选项默认在使用后刷新”的说明；保留 V0.2.4 的全部工作区功能。

## 验证与适用范围

- 类型检查及 89 项自动测试通过。
- 从最终 ZIP 解压出的应用，在正常、中文含空格、缺失父目录、路径指向文件及拒绝写入五种临时目录条件下均通过启动和版本检查。
- 正常用户环境保留 Chromium 默认沙箱；另用受限 Windows 令牌复现旧版 NSIS 报错，并确认兼容包可启动。受限令牌测试单独使用测试参数，不影响发布包的默认启动方式。
- 关键词和工作区界面回归通过。
- 本机已复现相同错误，但尚未取得受影响机器的系统、路径和权限信息，因此不能断定对方具体是目录无效、权限、磁盘或其他环境因素。中文路径本身在本机测试中通过。
- 本次绕过的是 NSIS 启动器对临时目录的依赖；编辑器仍需要正常的用户配置目录与 Mod 文件权限。

## 使用

无需安装。已有配置继续使用原用户配置目录；首次运行可选择 Mod 根目录。软件未进行代码签名。

详细复现与验证记录见仓库 `docs/NSIS_STARTUP_INVESTIGATION_V0.2.5.md`。

# 字段模型与模块定义（对应 packages/editor-core/src/schema.ts）

## ModuleDefinition 常用标志位
| 字段 | 作用 |
|---|---|
| `dataRoot` | 按数据根节点名自动匹配 `Data/*.xml` |
| `dataFile` | 显式数据文件相对路径（优先于 dataRoot） |
| `dataFiles` | 多个数据文件绝对路径（配合文档切换器） |
| `localizeRoots` | 本地化根节点模板数组，根节点相同的本地化 XML 自动挂入 |
| `entity` | 实体 Schema（必填） |
| `preview` | ArtworkPreviewDef，卡图预览 + 点击跳转工作区 |
| `resource` | ResourceWorkspaceDef，资源型工作区（走 ImageWorkspace） |
| `readonly` | 只读（禁用保存/新增/删除/编辑） |
| `builtin` | 内容来自应用而非当前 Mod |
| `builtinImages` | 内置图片工作区（走 BuiltinImageWorkspace） |
| `builtinRegex` | 内置正则查看器（走 BuiltinRegexWorkspace）；modRegex 也必须带此标志才会路由 |
| `modRegex` | 可编辑 Mod 正则（复用 BuiltinRegexWorkspace，isEditable=true） |
| `regexRules` | 模块专属正则（RegexPanel） |
| `stripFields` | 加载时从每个实体中移除的字段名（如废弃字段 SpecialEffect / UseCustomInnerType） |

## EntitySchema
| 字段 | 作用 |
|---|---|
| `root` / `entity` / `idAttr` | 根节点名 / 实体名 / ID 属性名 |
| `entities` | 同一容器下可同时识别的多个实体名 |
| `entitySources` | 多实体/多容器来源（例如 effecttext 的 effectTextList 与 extraTextList），比单 containerPath 更通用 |
| `containerPath` | 实体在根下的容器路径（如本地化 `['cardDescList']`） |
| `displayField` | 列表显示的字段名（默认 Name） |
| `quickFields` | 简易模式显示的字段名集合 |
| `idNumeric` | ID 仅允许数字 |
| `headerFields` | 渲染在 ID 行右侧的字段名集合 |
| `locked` | 固定值（隐藏但始终写入，如 `TextId: '-1'`） |
| `defaults` | 新建实体默认值（字段名 -> 值） |
| `accentFromModuleId` | 列表文字颜色从该工作区同名 ID 取稀有度主题色 |
| `idOnlyList` | 列表只显示 ID，列宽随内容动态调整 |
| `fields` | 字段数组（见下） |

## FieldDef 类型（kind）
| kind | 用途 | 关键属性 |
|---|---|---|
| `text` | 单行文本 | `required`、`autocomplete: 'page-artwork' / 'page-ability'` |
| `int` | 整数 | `digitsOnly`（仅数字）、`min/max`、`optional`（新建时不写 0）、`widthClass` |
| `enum` | 单选 | `values`、`asChips`（chip 按钮）、`labels`、`colors`、`icons`、`dots`（色点）、`allowCustom` + `customNumeric`、`noIdToggle` |
| `multiline` | 多行文本 | `multiLineElements: true` → 每行一个元素；`false` → 始终单元素（内部可含换行） |
| `bool` | 布尔 chip | 选中描边 + 半透明底，支持 `showIds` 显示 XML 字段名 |
| `attrs` | 一个容器上的多个属性 | `attrs: ScalarFieldDef[]` |
| `attr` | 指定元素上的单个属性 | `element` + `attr` + `field`（如 Spec 上的 Cost/Range） |
| `multi` | 多值（多个同名元素） | `values`（预设选项，点击切换）+ `labels` |
| `marker` | 布尔标记元素（存在即 true） | 无子字段；注意：marker 勾选会写 `<Name/>`，若只想做 UI 开关而不写入，勿用 marker |
| `list` | 行列表（如骰子列表） | `item`、`attrs`、`maxItems`、`addLabel` |

通用 BaseFieldDef：`label`、`help`、`placeholder`、`widthClass`、`omitWhenEmpty`（值为空时从 XML 移除该元素）。

## LocalizationRootDef
`root` / `containerPath` / `entity` / `idAttr` / `fields`（name/label/kind: text|multiline）。

## ResourceWorkspaceDef
`dir`（相对 Mod 根）、`type: 'image'`、`bindModuleId`/`bindField`（选中回填到某字段）、`recursive`、`defaultEmpty`（默认不自动读，需手动重定向）、`square`（小方形图标，如 Buff 图标）。

## ArtworkPreviewDef（preview）
`field`（数据实体中的资源名字段）、`assetGlob`、`nameWorkspaceId`（点本地化名跳转）、`abilityWorkspaceId`（点能力跳转）。

## 引擎读写 API（packages/editor-core/src/document.ts，均从 @ruina/editor-core 导出）
- 列表：`listEntities(doc, schema)`、`insertEntity`、`removeEntity`、`moveEntity`、`createEntity(schema, id)`
- 文本：`getTextField(node, name)` / `setTextField(node, name, value)`（单元素）
- 多行：`getAllText(node, name)`（多元素合并，\n 连接）/ `setAllText(node, name, text)`（按行拆多元素）
- 多值：`getMulti(node, name)` / `setMulti(node, name, values)`（同名多元素）
- 属性：`getAttr(node, name)` / `setAttr(node, name, value)`
- 行列表：`getListRows(node, listField)` / `setListRows(node, listField, rows)`
- 通用：`getFieldValue(node, field)` / `setFieldValue(node, field, value)`（按 field.kind 分派）
- 其它：`removeField(node, name)`、`hasMarker(node, name)` / `setMarker(node, name, on)`、`makeElement(name, attrs?, text?)`

## 关键语义
- `getFieldValue`/`setFieldValue` 已按 field.kind 分派，新增自定义 case 时尽量复用它们；只有需要“混合节点（文本 + 属性）”“条件互斥写入”等特殊逻辑时才直接操作 node。
- `createEntity` 对 text/multiline 默认写空元素、int 默认写 0（除非 `optional: true`）、enum 写 `values[0]`、bool 写 false；随后应用 `defaults`，再应用 `locked`。
- `stripFields` 在 `store.ts ensureModuleDocs` 的 primary 绑定加载时生效。

# UI 模板与既有模式（apps/desktop/src/renderer/src/components）

## 工作区路由（WorkspaceView.tsx）
每个模块的渲染分支顺序：
1. 未选 Mod → 提示选 Mod
2. `builtinImages` → BuiltinImageWorkspace
3. `builtinRegex` → BuiltinRegexWorkspace
4. `resource` → ImageWorkspace
5. 其余 → 通用三栏 XML 布局（列表 + 编辑区 + 本地化/预览 + 工具抽屉）

三栏布局要点：
- `viewMode`：`brief` / `detail` / `source`；`noBrief` 时简易不可用。
- `dataDoc` 用 `primaryLang[module.id]` 选择主文档，回退顺序：当前语言 → cn → 第一个。
- `refs = listEntities(dataDoc.doc, module.entity)`；`entity = refs.find(id === selectedId)`。
- 左侧列表 `DataPanel` / `EffectTextListPanel`（effecttext 专用）。
- 中间编辑区：brief → SummaryPanel（cardinfo 用 CardBriefPanel），source → SourcePanel，detail → FormPanel。
- 底部 ProofPanel 挂在 cardname/cardability/passiveability/effecttext。
- 右侧工具抽屉 `ToolDrawer` + 对应 Tools 组件。

## 顶部工具栏（WorkspaceToolbar.tsx）
- 视图模式：简略/详细/源码（`viewMode`）。
- 本地化文档下拉：`primaryLang[module.id]` + `setPrimaryLang`，选项来自实际文档 label，末尾加“无” `__none__`。
- 新增/复制/删除/上移/下移/校验修正/保存本模块，统一模板 + 操作后弹窗/状态反馈。

## 详细区（FormPanel.tsx）
- 顶部 ID 包裹框（`idOnlyList` 时 ID 框 w-full）；`headerFields` 放右侧。
- `boolFields` 以“属性”组渲染（右侧 `#ID` 切换显示字段名），chip 选中用 `accentColor` 描边+半透明底。
- `bodyFields` 逐个渲染；特殊字段用自定义 case：SkinChange / MapChange / Priority / InnerType / UseCustomInnerType / Desc(卡牌能力双模式)。
- 字段渲染统一走 `FieldEditor`；`Name` 用 `LinkedNameField`（点击跳转书页名称）。
- 校验问题显示在底部（`issues`），通过显示 `valid`。

## 字段渲染（FieldEditor.tsx）
- `enum` + `asChips`：chip 按钮，支持 `labels`/`colors`/`dots`（色点）/`icons`（图标）；选中 `accentColor` 描边；`showIds` 显示真实 ID；`allowCustom` + `customNumeric` 提供自定义输入。
- `bool`：chip，选中描边；`showIds` 显示 XML 字段名。
- `multiline`：`AutoTextarea`（最小高度 + 内容增高自动扩展）。
- `list`：行列表，行内 `attrs` 网格编辑，支持上下移动/删除/新增；`maxItems` 未开奇点时限制数量。
- `marker`：checkbox 卡片。
- `attr`：ScalarEditor 渲染其 `field`。
- `text` + `autocomplete`：`AutocompleteInput`（VS 风格下拉补全）。

## 列表（DataPanel.tsx）
- 虚拟滚动（`@tanstack/react-virtual`），固定行高 36；远端行测试用 `store.select(id)`，不要点未渲染行。
- 搜索：`idOnlyList` 时搜 ID+Desc，否则搜 ID/Name/Desc。
- 本地化按钮：`localizedNames`（纯文本）或 `localizedRender`（ReactNode 富文本）。`localizedRender` 存在时走非虚拟化列表，用于书页能力的正则格式多行显示 + ID 灰色小字头部。
- 颜色：`accentLookup`（跨工作区稀有度色）或 `cardAccent(node)`。

## 预览与正则
- `RegexText.tsx`：正则渲染，语法 `(~`→`<`、`~)`→`>`、`[X]` 黄+空格、`HatKeyword/HatKeywordLink/HatKeywordIcon` 内联 token、`(~u~)/(~b~)/(~i~)/(~color=#RRGGBB~)`。
- `useRegexRules.ts`：当前生效词条 Map（奇点开启才非空），合并 原版正则 + 奇点正则 + Mod EffectText。
- `previewRules.ts`：`parseRegexXml` / `extractEffectTextEntries` / `getBuiltinRegexEntries`，词条来自 `BattleEffectTextRootExtra.extraTextList.BattleEffectTextExtra`。
- `AbilityDescPreview.tsx`：书页能力右侧预览（`RegexText text=desc rules=rules`）。

## 资源工作区（ImageWorkspace.tsx）
- 平铺图片、导入（路径/拖拽）、删除、重命名、手动重定向、保存路径记忆。
- 平铺/实际（文件夹结构）切换；`square` 时小方形显示（Buff 图标）。

## 当前文档选择（WorkspaceToolbar + store）
- 顶部下拉叫「当前文档」（原「本地化文档」），按 **path** 选择：store 字段 `primaryDocPath[module.id]`，与 `primaryLang`（语言）分离。
- `setPrimaryDoc(moduleId, path)` 只设置 path，不覆盖 `primaryLang`；选「无」时 `setPrimaryLang(moduleId,'__none__')` + `setPrimaryDoc(moduleId,'')`。
- `ensureModuleDocs` 只在首次（`primaryLang`/`primaryDocPath` 尚未设置）写默认值，保留用户已选（含「无」），避免切模块回来被重置。
- 「无」时 `dataDoc` 为 undefined → 编辑区空、新增/删除/上移/下移/移除按钮自动禁用。
- 下拉项：文件名 + 小字语言；**仅当 `d.lang` 为真实语言（非 undefined、非 `unknown`）才显示语言后缀**，数据文档不显示「· 语言」；触发器与选项做 truncate + title 提示。
- 手动导入/删除：`importDoc(moduleId)`（`api.pickXmlFiles` 多选 xml/txt）、`removeDoc(moduleId, path)`；通过 `docOverrides`（localStorage 持久化，key = `modPath::moduleId`，add/remove 数组）记录，`ensureModuleDocs` 应用覆盖。
## 关联文本显示规则（本地化优先、回退原始）
- `LinkedNameField`：左「名称」（原始数据）＋右「本地化名称」（当前本地化文档），各占一行一半。
- 找本地化文档优先 `primaryDocPath[locWorkspaceId]`（精确选中），再回退 `primaryLang` → `cn` → 第一个；无文档或选「无」时只显示/编辑原始名称。
- **`linked` 判定**：用 `(module.dataFiles?.length || module.dataFile || module.dataRoot)`，不要只查 `module.dataRoot`（scan 后模块用 `dataFiles` 替换掉 `dataRoot`，只查 dataRoot 会导致名称不拆分）。
- 其它关联展示（预览、校对、列表本地化）同规则：有本地化优先本地化，否则用 cardinfo/passivelist 等数据文件里的原始名称与描述。
## 书页故事（BookStory）
- `bookStoryModule` 是本地化驱动工作区（无 dataFile）；`scanMod` 会把 `Data/BookStory.xml`（根 `BookDescRoot`）与 `Localize/Books` 一起归入 primary 文档（两者 root 相同），因此下拉里能看到 Books_cn / Books_en / BookStory 三份。
- `scanMod` 第一层循环：先 parse 出 root，再判断 `data/resource/artwork/char/bufficon` 目录下、root 不是 `KNOWN_LOC_ROOTS` 才跳过；这样 `Data/BookStory.xml` 这类「数据目录里但根是本地化根」的文件能被正确导入。

- `bookStoryModule` 用 `dataFile: 'BookStory.xml'` 读取 `Data/BookStory.xml` 作为数据区（根 `BookDescRoot`，实体 `BookDesc`），Books 本地化（Localize/Books）作为本地化区；即使 BookStory.xml 为空也照常读取。

# 踩坑清单（务必先读）

1. **首次打开模块必须加载全部关联文档**：`ensureModuleDocs` 不要看到已有 binding 就提前 return；否则首次打开会缺本地化下拉、缺颜色。
2. **跨工作区依赖要预加载**：`accentFromModuleId`、`preview.nameWorkspaceId`、`preview.abilityWorkspaceId` 都要加入 WorkspaceView 的 `dependencyIds` 并 `ensureModuleDocs`，不能等用户先点来源工作区。
3. **本地化默认语言优先中文**：`ensureModuleDocs` 设 `primaryLang` 时先找 `cn`/`zh` 再回退第一个；`dataDoc` 回退也要按编辑器语言 → cn → 第一个。否则首次打开随机显示英文。
4. **detectLang 要识别文件名下划线后缀**（`_cn.xml`/`_en.xml`/`_ja.xml`），不能只靠内容比例，否则中英混合文本会被误判。
5. **右侧工具抽屉始终挂载**，用 `translate-x-full` 做动画；不要条件卸载，否则没有滑入/滑出动画。
6. **多行描述统一用 `AutoTextarea`**，不要写死 `rows` 的普通 textarea。
7. **多容器结构用 `entitySources`**（如 effecttext 的 effectTextList + extraTextList），不要单个 `containerPath` 硬套。
8. **按钮禁用要给出明确来源**：同步/删除按钮依赖“源文档存在 + 目标文档存在”，缺一个就禁用是设计意图，但必须自动加载依赖文档。
9. **校验修正/保存本模块要有弹窗反馈**：统一走顶部按钮模板，操作后弹出 store 状态结果，不能只改状态栏。
10. **列表颜色/图标依赖模组正则时**：传入 `buffIcons` 并 `loadBuffIcons`，否则自定义 KeywordIconId 无法解析。
11. **React 重复 key**：同一关键字在同一文本多次出现时，token 的 key 用位置索引（`k-${i}` / `b-${i}` / `r-${i}`），不要用 `entry.id`，否则切换会残留/错位。
12. **识别名最长匹配**：短词是长词前缀时（如“破裂” vs “破裂易损”），匹配必须按长度降序，短词才不会先命中。
13. **文件名可选 s**：`EffectText`/`EffectTexts` 都要匹配（`/effecttexts?/i`）。
14. **路由标志遗漏**：`modRegex: true` 但没有 `builtinRegex: true` 会掉进通用 XML 布局显示为空。
15. **只读 textarea**：用 `ValueInput`（disabled + readOnly），值随选中项更新；残留先排查 key 冲突。
16. **marker 会写入 `<Name/>`**：只想做 UI 开关（不产生节点）时不要用 `kind:'marker'`，改用本地 state + `editData`/`removeField` 精确控制；并用 `stripFields` 清理历史遗留节点。
17. **混合节点（文本 + 属性）**：`<CopyInnerTypeFrom Pid="@origin">123</...>` 这种“既有文本又有属性”用 `kind:'attr'` 写属性 + `kind:'int'/text` 写文本，分两次 `setFieldValue`。
18. **multiline 的 multiLineElements**：`true` 每行一个 `<Desc>`（独立），`false` 单 `<Desc>`（连续，内部可 \n）；两种格式可能在同一文件内混合，需按实体检测而非按文档一刀切。
19. **列表富文本本地化**：`DataPanel` 的 `localizedRender` 返回 ReactNode 时走非虚拟化列表（固定行高会溢出），并用 `whitespace-pre-wrap` + `RegexText` 与预览一致。
20. **PowerShell 编码/换行**：写文件用 UTF8 无 BOM；`.ps1` 若含中文要写 BOM（PowerShell 5.1 才读得对）；`store.ts` 是 CRLF，字符串替换前确认换行。
21. **headless 自测**：改 UI 后必须跑 `pnpm typecheck` + `pnpm test` + `pnpm --filter @ruina/desktop build` + 无界面自测（RUINA_* 环境变量），不能只交给用户测。

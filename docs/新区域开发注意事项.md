## 1. 新增工作区的标准路径
1. 在 `packages/schemas/src/` 新建模块定义（参考 `cardinfo.ts`、`artwork.ts`、`singularity.ts`）。
2. 在 `packages/schemas/src/index.ts` 导入并注册。
3. 若需要出现在左侧连线图，在 `apps/desktop/src/renderer/src/components/WorkspaceLinkGraph.tsx` 的 `groups` 里加一组 `{ title, icon, ids, disabled }`。
4. 若需要自定义渲染（非 XML 三栏），在 `apps/desktop/src/renderer/src/components/WorkspaceView.tsx` 加分支。

## 2. 模块标志位（packages/editor-core/src/schema.ts）
- `dataRoot` / `dataFile` / `dataFiles`：数据文件来源。
- `localizeRoots`：本地化根节点模板。
- `resource`：资源型工作区（图片库，走 `ImageWorkspace`）。
- `readonly`：只读（禁用保存/新增/删除/编辑）。
- `builtin`：内置（来自应用而非当前 Mod）。
- `builtinImages`：内置图片工作区（走 `BuiltinImageWorkspace`）。
- `builtinRegex`：内置正则查看器（走 `BuiltinRegexWorkspace`）。**注意：`modRegex` 模块也必须同时带 `builtinRegex: true`，否则不会路由到正则查看器。**
- `modRegex`：可编辑的 Mod 正则工作区（复用 `BuiltinRegexWorkspace`，`isEditable = true`）。
- `regexRules`：模块专属正则（见 `RegexPanel`）。

## 3. 本地化文档下拉（复刻书页名称）
标准逻辑：用 store 的 `primaryLang[module.id]` + `setPrimaryLang(module.id, lang)`。
- 选项来自实际存在的文档，显示 `label`（简体中文 / English / 日本語），**未实装的语言不要显示**。
- 末尾追加「无」选项 `__none__`，选中后列表清空。
- 当前 `BuiltinRegexWorkspace` 已统一此逻辑：内置正则用打包资源 + `langFullLabel`，模组正则用 `localizeFiles` 的 `label`。

## 4. 正则替换引擎（奇点）
- 组件：`components/RegexText.tsx`。
- 词条来源：`lib/useRegexRules.ts`（开启奇点才非空），合并 原版正则 + 奇点正则 + Mod EffectText。
- 解析：`lib/previewRules.ts` 的 `parseRegexXml` / `extractEffectTextEntries`，读取 `extraTextList` 下的 `BattleEffectTextExtra`。
- 语法：`(~` 转 `<`，`~)` 转 `>`；标签 `HatKeyword / HatKeywordLink / HatKeywordIcon`；`[X]` 始终黄色+小空格。
- 识别名匹配：`scope` 过滤（ability/passive/self/all），`hasBracket` 决定匹配 `[识别名]` 还是裸识别名。

## 5. 本次踩过的坑（务必注意）
1. **React 重复 key**：同一关键字在同一文本中出现多次时，token 的 key 不能用 `entry.id`，必须用位置索引（`k-${i}` / `b-${i}` / `r-${i}`），否则切换词条会出现“旧内容残留/错位”。
2. **识别名最长匹配**：`破裂` 是 `破裂易损` 的前缀，匹配必须按长度降序（最长优先），否则短词先命中。
3. **文件名可选 s**：`EffectText` / `EffectTexts` 都要匹配（正则 `/effecttexts?/i`），不要写死单复数。
4. **路由标志遗漏**：`modRegex: true` 但没有 `builtinRegex: true` 会导致工作区掉进通用 XML 布局而显示为空。
5. **只读 textarea**：只读详情用 `ValueInput`（disabled + readOnly），值随选中项更新；如仍出现残留，优先排查 key 冲突，而非 React 状态。

## 7. 新区域开发近期再次踩坑清单（2026-08-16 增补）
1. **首次打开模块必须加载全部关联文档**：`ensureModuleDocs` 不能看到已有 binding 就提前 return；否则首次打开某区域会只加载部分本地化文件，导致下拉框缺失、列表颜色缺失等问题。
2. **`accentFromModuleId` 依赖也要预加载**：列表若要从另一个工作区取稀有度颜色，必须在进入当前工作区时主动 `ensureModuleDocs(accentFromModuleId)`，不能等用户先点一次来源工作区。
3. **右侧功能抽屉必须始终挂载、用 transform 做动画**：收起时面板要完全 `translate-x-full`，只留小箭头；不要用条件卸载，否则没有滑入/滑出动画。
4. **描述框统一使用 `AutoTextarea`**：所有多行描述应支持最小高度 + 内容增高自动扩展；新区域不要再写死 `rows` 的普通 textarea。
5. **EffectText 文件可能同时包含两个容器**：`effectTextList` 放 `BattleEffectText`，`extraTextList` 放 `BattleEffectTextExtra`。新模块遇到类似结构应使用 `EntitySchema.entitySources`，而不是单个 `containerPath`。
6. **按钮禁用状态要给出明确来源**：同步/删除类按钮应明确依赖“源文档存在 + 目标文档存在”；缺一个就禁用是设计意图，但必须自动加载依赖文档，否则会误判为 bug。
7. **校验修正 / 保存本模块要有弹窗反馈**：工作区顶部按钮统一走模板，并在操作后弹出当前 store 状态结果，不能只改状态栏。
8. **新区域列表颜色/图标依赖模组正则时**：要传入 `buffIcons` 并加载 `loadBuffIcons`，否则自定义 KeywordIconId 无法解析。

9. **所有跨工作区依赖都要在 WorkspaceView 预加载**：`accentFromModuleId`、`preview.nameWorkspaceId`、`preview.abilityWorkspaceId` 都应加入 `dependencyIds` 并统一 `ensureModuleDocs`，不要依赖用户先点开来源工作区。

10. **本地化默认语言必须优先中文**：`ensureModuleDocs` 设置 `primaryLang` 时不能直接取 `primaries[0]`，应优先 `cn` / `zh`，再回退到第一个文档；正则工作区的 `selectedLang` 也要同样优先 `cn`。否则首次打开会随机显示英文。

11. **本地化文件名后缀不参与默认语言排序**：`detectLang` 会同时看路径和内容，`_cn` / `_en` 有无后缀都只是识别语言；默认选择必须由编辑器语言决定，不能依赖文件名后缀先后。

12. **WorkspaceView 的 dataDoc 回退也要按编辑器语言**：不能直接 `?? primaryDocs[0]`，应先找当前编辑器语言，再找 `cn`，最后才回退第一个文档。否则首次渲染会短暂显示英文。

13. **detectLang 必须识别文件名下划线后缀**：`_cn.xml` / `_en.xml` / `_ja.xml` 这类后缀不能只靠内容比例判断；否则中英混合文本会被误判为英文，导致首次打开本地化区域显示错误语言。

- 内置资源已同步：

## 二、发布窗口需执行
1. 确认版本号使用 `V0.2.0`；若改版本号，需同步以下位置：
   - `apps/desktop/package.json` 的 `"version"`
   - `apps/desktop/src/renderer/src/App.tsx` 左上角版本标签（当前为 `V0.1.2`）
   - `docs/CHANGELOG.md` 顶部与 `docs/RELEASE_NOTES_V<版本>.md`
2. 打包 Windows 单文件：`pnpm --filter @ruina/desktop dist:win`（需要联网 + elevated 权限）
3. 复制 exe 到桌面
4. Linux 产物交给 `.github/workflows/release.yml`（推送 `v*` 标签时自动构建 Windows + Ubuntu）
5. GitHub Release：按 `ruina-packaging` skill 的 `gh release create` 流程执行

## 三、注意事项
- GitHub 附件名统一 ASCII：`HatLibraryOfRuinaEditor-0.2.0-portable.zip`、`HatLibraryOfRuinaEditor-0.2.0.AppImage`、`HatLibraryOfRuinaEditor-0.2.0.deb`
- 发布后提醒用户：桌面快捷方式会自动构建最新版
- 当前仓库无 `scripts/*.ps1`（`package-win.ps1` / `publish-github.ps1` 未落盘），请直接按 skill 内联命令执行

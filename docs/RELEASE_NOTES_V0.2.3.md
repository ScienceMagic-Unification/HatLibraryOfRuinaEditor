# 帽子的废墟图书馆编辑器 V0.2.3

## 下载

- Windows x64 单文件便携版：`HatLibraryOfRuinaEditor-0.2.3-portable.exe`，下载后直接运行。
- Windows ZIP：`HatLibraryOfRuinaEditor-0.2.3-portable.zip`，包含中文命名的 EXE 和本次更新说明。
- 文件校验：`SHA256SUMS.txt`。

## 本次更新

- 重构敌我核心书页的抗性、皮肤、被动与专属卡牌编辑；皮肤限制为单项，高级自定义专属卡牌独立设置并标注 ExtraBridge。
- 核心预览显示实际卡牌名称和完整被动描述，支持点击跳转书页与被动工作区。
- 内置原版战斗书页、被动能力与书页能力，统一预览格式。
- 奇点能力工作区采用书页能力的页面布局，仅显示书页/骰子能力；接入贯通、盾击等能力及中英日韩资源。
- 补全奇点图片，去除“其他”栏中的重复项目，修复佚亡关键词图标显示。
- 修复带 `value` 属性的 HatKeyword 显示。例如 `(~HatKeyword id="Hat_Enchantments_MultipleHit_Keyword" value="2"/~)` 现在显示连击图标及“连击:2”。
- 参数支持单双引号、属性换序、空格、表达式及普通文字；关键词库支持参数编辑，数值关键词补全可直接填写参数。
- 完善 XML 转义、四语预览、关键词迁移搜索、重复词条汇总及骰子适用条件。预览不改写用户原文，也不执行游戏 C# 能力。

## 验证

- 类型检查及 66 项自动测试通过。
- 四语参数预览、图标、提示、参数编辑、自动补全及 XML 保存回读通过界面验证。

## 使用

首次运行可选择 Mod 根目录。便携版无需安装；未进行代码签名。保存前建议保留 Mod 备份。

问题反馈请通过仓库 Issues 提供复现步骤和相关 XML 片段。

# 图片大工作区 —— 分步实施计划

> 目标：新增“图片”大工作区（类似“书页”大工作区），右侧连线到 书页图片 / buff 图标 / 其他图片 三个工作区；其中“书页图片”是后续其他图片工作区的模板。

## 架构约束（务必遵守）
- 共享文件不要改：`store.ts`、`WorkspaceView.tsx`、`i18n.tsx` 只允许按既有模式扩展，不要重构。
- 新模块统一走 `packages/schemas/src/*.ts` + `index.ts` 注册。
- 图片资源操作通过主进程 IPC，渲染进程不要直接碰文件系统。

---

## 阶段 1：主进程图片资源 API
文件：`apps/desktop/src/main/ipc.ts`、`apps/desktop/src/main/files.ts`、`apps/desktop/src/preload/index.ts`、`index.d.ts`
新增 IPC：
1. `fs:list-images(dir)` → 返回图片文件名/大小/修改时间；
2. `fs:import-image(dir, srcPath)` → 复制进目录（重名自动加 `(1)`）；
3. `fs:import-image-data(dir, fileName, base64)` → 拖拽导入；
4. `fs:delete-image(path)` → 删除（回收站或直接删，需二次确认）；
5. `fs:rename-image(path, newName)` → 重命名（保持扩展名）。

安全：路径必须落在 Mod 资源目录内；文件名过滤非法字符。

---

## 阶段 2：新增“书页图片”工作区模块
文件：`packages/schemas/src/artwork.ts`
- `id: 'page-artwork'`，`title: '书页图片'`；
- `resourceDir: 'Resource/CombatPageArtwork'`；
- 这是一个**资源型工作区**，不是 XML 工作区：`entity` 留空或使用特殊占位。
- 在 `packages/schemas/src/index.ts` 注册。

同时在 `i18n.tsx` 补齐：
- `module.page-artwork`、`module.buff-icons`、`module.other-images`
- 图片操作按钮文案：导入 / 删除 / 重命名 / 手动重定向 / 拖拽导入提示。

---

## 阶段 3：图片工作区 UI（模板）
新文件：
- `components/ImageWorkspace.tsx`：平铺展示图片（虚拟网格）；
- `components/ImageCard.tsx`：缩略图 + 文件名 + 悬停操作（重命名/删除）；
- `components/ImageImportDrop.tsx`：拖拽区域。

行为：
1. 默认读取 `Mod\Resource\CombatPageArtwork`；
2. 顶部按钮“手动重定向”选择其他文件夹（调用 `dialog:pick-mod` 变体或新增 `dialog:pick-directory`）；
3. 平铺展示全部图片；
4. 导入：按钮选择路径 + 拖拽图片进工作区；
5. 删除/重命名：二次确认。

## 阶段 4：战斗书页自动补全
文件：`apps/desktop/src/renderer/src/components/FieldEditor.tsx`
- 给 `text` 字段增加可选 `autocomplete?: 'page-artwork' | 'page-ability'`（Schema 扩展）。
- 当输入“书页图片 / 书页能力”时，基于当前已有名称显示 VS 式下拉自动补全。
- 补全数据来源：
  - 书页图片：`store` 中资源列表（新增 `store.assets` 或由模块加载）；
  - 书页能力：`docs` 中书页能力主文档的 ID 列表。
- Schema 更新：
  - cardinfo `Artwork` 字段：`label:'书页图片'`、`autocomplete:'page-artwork'`；
  - cardinfo `Script` 字段：`label:'书页能力'`、`autocomplete:'page-ability'`；
  - `BehaviourList` 的 `Script` 字段：`autocomplete:'page-ability'`。
